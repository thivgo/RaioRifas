> **RaioRifas** é uma solução desenvolvida para simplificar e agilizar a criação, gestão e sorteio de rifas. O projeto foca na integridade dos dados e na transparência do processo de sorteio.

---

## 💻 Sobre o Projeto

O **RaioRifas** nasceu da necessidade de gerenciar sorteios de forma mais organizada do que as planilhas manuais. O sistema permite o cadastro de participantes, a venda de números e a realização do sorteio de forma automatizada e auditável.

### 🎯 Funcionalidades Principais

- [x] **Gestão de Rifas:** Criação e edição de múltiplas rifas simultâneas.
- [x] **Controle de Números:** Visualização em tempo real de números disponíveis, reservados e pagos.
- [x] **Sorteio Automático:** Algoritmo para escolha aleatória do vencedor com base nos números comprados.
- [x] **Interface Responsiva:** Design amigável para acesso via mobile ou desktop.
- [ ] **Integração com Pagamentos:** (Em desenvolvimento/Futuro) Link direto para comprovantes.

## 🛠 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

* **Linguagem:** Python 🐍 (Foco em lógica e backend)
* **Banco de Dados:** SQL (Para persistência segura dos dados dos participantes)
* **Frontend:** HTML5, CSS3, JavaScript (Interface do usuário)
* **Ferramentas:** Git & GitHub

## 🚀 Como Executar o Projeto

### Pré-requisitos

Antes de começar, você precisará ter instalado em sua máquina as seguintes ferramentas:
[Git](https://git-scm.com), [Python 3.x](https://www.python.org/).
Além disso, é bom ter um editor para trabalhar com o código como o [VSCode](https://code.visualstudio.com/).

### 🎲 Rodando a Aplicação

```bash
# Clone este repositório
$ git clone [https://github.com/thivgo/RaioRifas.git](https://github.com/thivgo/RaioRifas.git)

# Acesse a pasta do projeto no terminal/cmd
$ cd RaioRifas

# Instale as dependências (se houver um requirements.txt)
$ pip install -r requirements.txt

# Execute a aplicação
$ python main.py
# (Ou o comando específico do seu framework, ex: flask run / python manage.py runserver)
